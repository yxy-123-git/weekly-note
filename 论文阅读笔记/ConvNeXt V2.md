# ConvNeXt V2：论文理解笔记

> **论文**：ConvNeXt V2: Co-designing and Scaling ConvNets with Masked Autoencoders  
> **会议**：CVPR 2023  
> **阅读重点**：理解 FCMAE 与 GRN 为什么提出、如何配合，以及实验支持什么结论。

## 一、论文要解决什么问题？

ConvNeXt V1 已经证明：经过改进的卷积网络也能在视觉识别中取得很好的效果。但它主要是在**有监督分类**条件下设计的，即输入图片，让模型预测人工标注的类别。

另一条研究路线是 MAE（掩码自编码器）：遮住图片的一部分，让模型根据剩余内容重建被遮挡区域。这个过程不需要类别标签，可以先学到图像表示，再迁移到分类、检测等任务。

作者想解决的问题是：**能否让 ConvNeXt 也像 ViT 一样，有效利用掩码自监督预训练？**

直接组合两者并不顺利，主要遇到两个困难：

1. **计算方式不匹配**：ViT 可以只接收可见 patch 组成的序列；卷积需要保留二维空间关系，不能简单删掉遮挡位置后把剩余内容拼起来。
2. **学到的特征不够丰富**：即使改造了训练框架，ConvNeXt V1 在掩码预训练中仍出现通道响应重复的问题，影响下游效果。

论文的解决思路因此分为两步：先设计适合卷积的 **FCMAE**，再通过 **GRN** 改进网络内部的特征学习。

## 二、FCMAE：让卷积网络有效学习遮挡图像

### 2.1 完整过程

FCMAE 是 Fully Convolutional Masked Autoencoder，即全卷积掩码自编码器。训练过程可以理解为：

**遮挡部分图片 → 编码可见区域 → 重建缺失区域 → 根据重建误差更新网络。**

具体包含三个环节。

**第一，随机遮挡。** 论文遮挡约 60% 的 32×32 图像 patch。因为 ConvNeXt 有多个下采样阶段，作者让不同分辨率的掩码保持对应关系，保证各层处理的是同一组可见区域。

**第二，稀疏编码。** 编码器使用子流形稀疏卷积，保留可见位置的空间坐标，只在有效位置进行相关计算。这样既维持卷积需要的二维结构，又避免把遮挡位置当成普通输入持续处理，并维持正确的掩码约束。

**第三，轻量重建。** 解码器使用一个 ConvNeXt block，根据编码后的可见特征和遮挡位置的 mask token 重建图像。重建损失采用均方误差，目标是逐 patch 归一化后的像素，而且**只在被遮挡区域计算损失**。

### 2.2 为什么这样设计？

只在遮挡区域计算损失，是为了让模型利用上下文预测未知内容，而不是主要靠复制已经看到的像素完成任务。

使用轻量解码器，则是为了把主要表示学习能力放在编码器上，同时降低重建分支的训练成本。

完成预训练后，下游分类不再使用重建解码器。编码器转为密集卷积，处理完整图片，再接分类头进行有监督微调。

因此，**“自监督”指预训练不使用类别标签，并不代表后续分类微调也不用标签。**

### 2.3 为什么只有 FCMAE 还不够？

FCMAE 解决了“卷积网络如何进行掩码训练”的问题，但作者发现，直接使用 ConvNeXt V1，效果仍没有稳定超过其强有监督基线。

这说明，训练流程能运行，不等于原有结构就能充分利用这个学习目标。作者于是进一步检查网络中间的特征。

## 三、GRN：缓解通道特征重复

### 3.1 什么是论文中的“特征坍塌”？

一个卷积层通常有很多通道，每个通道都对应一张特征图。理想情况下，不同通道能够提供不同的信息。

作者在 Figure 3 中观察到，V1 经过 FCMAE 预训练后，通道扩展 MLP 中出现许多不活跃、饱和或彼此相似的特征图。这意味着虽然通道很多，但它们没有充分学到不同的内容。

论文称之为 **feature collapse（特征坍塌）**。这里主要指通道特征冗余，并不是说模型对所有图片都输出同一个结果。

Figure 4 进一步计算通道之间的余弦距离：V1 + FCMAE 的距离偏低，说明通道模式更相似；加入 GRN 后，距离整体提高，为特征多样性改善提供了证据。

### 3.2 GRN 怎么做？

GRN 是 Global Response Normalization，即全局响应归一化。它的核心是：**先看每个通道在整张特征图上的响应有多强，再把它放到所有通道中比较，最后调整原特征。**

**第一步：计算每个通道的响应强度。**

对第 $i$ 个通道的空间特征图 $X_i$ 求 L2 范数：

$$
g_i=\|X_i\|_2.
$$

可以把 $g_i$ 理解为该通道整张特征图的响应能量，而不是某一个像素的值。这对应论文 Eq. (1) 的全局聚合。

**第二步：计算相对响应。**

实际实现使用当前通道响应除以所有通道的平均响应：

$$
n_i=\frac{g_i}{\frac{1}{C}\sum_{j=1}^{C}g_j+\epsilon}.
$$

$C$ 是通道数，$\epsilon$ 是避免分母为零的小常数。当前通道的权重由自己和其他通道共同决定，形成通道间的相对比较。

论文 Eq. (2) 写成除以响应总和，脚注说明实际还乘以通道数；因此 Algorithm 1 中采用均值作为分母，两者的差别有明确说明。

**第三步：调整特征，并保留原输入。**

结合论文 Eq. (3) 及其后的残差设计，最终输出可以写成：

$$
Y_i=X_i+\gamma_i(X_i n_i)+\beta_i.
$$

$\gamma_i$ 和 $\beta_i$ 是可学习参数，初始化为零，所以模块刚开始等价于保留输入，再逐步学会如何调整通道响应。

直观地说，GRN 让通道不再只看自己的数值，而是在其他通道的参照下调整响应。实验显示，这有助于缓解通道冗余；但它并不强制通道彼此正交，也不是简单地始终压低最强通道。

### 3.3 ConvNeXt V2 改了哪里？

根据 Figure 5，V2 在 block 的通道扩展和 GELU 之后加入 GRN，并移除原来的 LayerScale，仍保留 LayerNorm 和外部残差连接。

可以这样区分三个概念：

- **FCMAE**：负责怎么预训练，是学习框架。
- **GRN**：负责怎么调整通道特征，是网络模块。
- **ConvNeXt V2**：采用新 block 设计的网络架构。

GRN 不需要额外的复杂门控网络，只新增少量仿射参数，所以模型规模基本不变。

## 四、实验结果应该怎么理解？

### 4.1 核心实验：两项改动配合起来是否有效？

Table 3 报告 ImageNet-1K 分类结果，指标为 Top-1 准确率（%）。其中 FCMAE 采用 800 epoch 预训练。

| 方案 | Base | Large |
| --- | ---: | ---: |
| V1 + 有监督训练 | 83.8 | 84.3 |
| V1 + FCMAE | 83.7 | 84.4 |
| V2 + 有监督训练 | 84.3 | 84.5 |
| V2 + FCMAE | 84.6 | 85.6 |

这张表是理解整篇论文最重要的证据：

- 只给 V1 加 FCMAE，收益很有限，Base 甚至没有超过有监督基线。
- 只使用 V2 架构做有监督训练，有改善，但 Large 的提升不大。
- V2 与 FCMAE 配合使用，才获得更明显的提升，Large 相对 V1 有监督提高 1.3 个百分点。

**所以论文强调“协同设计”：预训练效果不只由训练目标决定，还取决于网络是否适合这个目标。**

需要注意，预训练加微调的总训练预算更高，这张表主要比较最终效果，不能据此说相同训练时间下也有同样收益。

### 4.2 消融实验：为什么选择这些设计？

| 关键对照 | 论文结果 | 说明 |
| --- | --- | --- |
| 解码器设计，Table 1a | 单 ConvNeXt block 与带跳连 UNet 均为 83.7；训练时间分别为 7.7、12.9 小时 | 更复杂的解码器没有带来更好的微调效果，轻量设计更划算 |
| 响应聚合，Table 2a | 全局均值 83.7；L1 范数 84.3；L2 范数 84.6 | L2 聚合在该设置中效果最好 |
| 残差连接，Table 2c | 无残差 84.0；有残差 84.6 | 保留输入有助于优化 |
| GRN 使用阶段，Table 2f | 微调时移除 78.8；只在微调时加入 80.6；两阶段都使用 84.6 | 预训练和微调应保持结构一致 |

这些准确率均来自 ConvNeXt-Base 在 ImageNet-1K 上的微调。解码器时间是在指定 TPU-v3 / JAX 环境测得，不能直接当作任何 GPU 上的加速比例。

最后一组也涉及结构与已学权重不匹配，因此它直接支持的是“两阶段都保留 GRN”，不能把下降全部解释成某一种单独机制。

### 4.3 是否超过其他方法？

Table 4 显示，ConvNeXt V2 在 Base 和 Large 规模具有竞争力，但没有全面超过 Transformer。例如，同为 1600 epoch 预训练时，V2-L 为 85.8，ViT-L + MAE 为 85.9；V2-L 使用的参数更少。Huge 规模则为 V2-H 的 86.3 对比 ViT-H + MAE 的 86.9。

因此，这篇论文证明了**纯卷积网络也可以有效受益于掩码预训练**，而不是证明卷积在所有规模都优于 Transformer。

论文标题页强调的 **88.9%** 来自 Table 5 的 Huge 模型、512×512 输入，并经过额外的 ImageNet-22K 有监督中间微调。它不能与只用 ImageNet-1K、224×224 输入的结果直接归因比较。

### 4.4 学到的特征能否迁移到其他任务？

Table 6 在 COCO 上使用 Mask R-CNN：Base 模型从 V1 有监督的 **50.3 box AP / 44.9 mask AP**，提高到 V2 + FCMAE 的 **52.9 / 46.6**。

Table 7 在 ADE20K 上使用 UPerNet：Base 模型的 mIoU 从 **49.9** 提高到 **52.1**。

这些结果表明，改进后的表示不仅适用于图像分类，也能迁移到检测和分割。但 ADE20K 上 Swin-B + SimMIM 为 **52.8**，仍高于 V2-B，因此优势取决于具体任务与配置。

## 五、如何把整篇论文串起来？

论文的逻辑是：

1. **提出问题**：ConvNeXt 在有监督学习中很强，但不能直接照搬 ViT 的 MAE。
2. **解决计算适配**：FCMAE 用稀疏卷积和轻量解码器，使卷积网络能够有效处理遮挡输入。
3. **发现表示问题**：能完成预训练之后，仍存在通道特征重复，影响学习效果。
4. **调整网络结构**：GRN 比较并校准全局通道响应，缓解特征坍塌。
5. **验证完整方案**：协同对照、消融和下游迁移实验共同说明，结构与训练框架需要配合设计。

**最终理解：ConvNeXt V2 的价值，不只是多加了一个模块，而是通过分析训练中的特征问题，让网络结构更适合自监督学习目标。**

论文也有边界：较长的预训练增加成本，最高精度使用额外标签与更高分辨率，部分任务或模型规模仍落后于对比方法。本地 PDF 无独立 Limitations 章节；这些边界来自正文实验及其比较条件。
