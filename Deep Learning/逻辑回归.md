## 1. 逻辑回归概览

逻辑回归（Logistic Regression）是一个**有监督学习的分类模型**，最常用于二分类。例如：是否流失、是否患病、是否点击、是否违约。

- 输入：样本特征 $\boldsymbol{x}$。
- 标签：通常是 $y \in \{0, 1\}$。
- 输出：样本属于正类（记作 1）的概率 $p \in (0, 1)$，而非直接输出类别。
- 分类：再按阈值将概率转成类别。常用阈值为 0.5，但可按业务成本调整。

### 1.1 核心流程

1. 线性部分先计算分数：

   $$z = \boldsymbol{w}^{\mathsf{T}}\boldsymbol{x} + b$$

2. 用 sigmoid 将分数映射成概率：

   $$p = \sigma(z) = \frac{1}{1 + e^{-z}}$$

3. 按阈值 $t$ 输出类别：

   $$\hat y = \begin{cases}1, & p \ge t \\ 0, & p < t\end{cases}$$

若正类定义为 A，且阈值为 0.6，则 $p \ge 0.6$ 预测为 A；否则预测为 B。

### 1.2 sigmoid 函数

$$\sigma(x) = \frac{1}{1+e^{-x}}$$

- 将任意实数 $(-\infty, +\infty)$ 映射到 $(0, 1)$。
- 单调递增；当 $x=0$ 时，$\sigma(x)=0.5$，也是曲线拐点。
- 导数形式简洁：

  $$\sigma'(x) = \sigma(x)\bigl(1-\sigma(x)\bigr)$$

### 1.3 易错点

`p_i` 表示“第 $i$ 个样本被预测为**正类**的概率”，不是“这个样本被分类正确的概率”。

## 2. 损失函数与最大似然估计

### 2.1 单个样本的正确类别概率

对一个样本，设预测为正类的概率为 $p$：

$$P(y \mid x) =
\begin{cases}
p, & y=1 \\
1-p, & y=0
\end{cases}
= p^y(1-p)^{1-y}$$

这符合直觉：

- 真实标签为 1 时，希望 $p$ 越大越好；
- 真实标签为 0 时，希望 $1-p$ 越大越好。

### 2.2 多个样本的似然函数

假设样本独立，$m$ 个样本同时被正确解释的联合概率（似然）是：

$$L(\boldsymbol{w}, b) = \prod_{i=1}^{m} p_i^{y_i}(1-p_i)^{1-y_i}$$

训练逻辑回归就是寻找参数 $\boldsymbol{w}, b$，使这个似然尽可能大，即**最大似然估计**。

### 2.3 从最大似然到交叉熵损失

连乘不便优化，因此先取对数，将连乘转成求和：

$$\log L = \sum_{i=1}^{m}\left[y_i\log(p_i)+(1-y_i)\log(1-p_i)\right]$$

最大化对数似然，等价于最小化其相反数，也就是二元交叉熵（log loss）：

$$\operatorname{Loss} = -\sum_{i=1}^{m}\left[y_i\log(p_i)+(1-y_i)\log(1-p_i)\right]$$

实践中常再除以样本数 $m$，取平均损失；最优点不变。

### 2.4 如何训练

用梯度下降或其变体迭代更新 $\boldsymbol{w}$ 与 $b$，使损失函数逐步减小。

## 3. scikit-learn 基本用法

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(
    solver="liblinear",
    penalty="l2",
    C=1.0,
)
model.fit(X_train, y_train)

# 正类概率与分类结果
y_prob = model.predict_proba(X_test)[:, 1]
y_pred = model.predict(X_test)
```

常用参数：

- `solver`：优化算法。`liblinear` 对小数据集通常较方便；`sag` / `saga` 更适合较大的数据集或稀疏数据。
- `penalty`：正则化类型。常见为 `"l2"` 或 `"l1"`。
- `C`：正则化强度的倒数；`C` 越小，正则化越强。
- 类别不平衡时，可考虑 `class_weight="balanced"`，并重点观察 Recall、F1、PR-AUC 等，而不只看 Accuracy。

> 兼容性提示：不同 `solver` 支持的 `penalty` 组合不同。`liblinear` 支持 L1/L2；`saga` 支持 L1/L2/elasticnet/无正则化。以当前 scikit-learn 版本文档与报错提示为准。

## 4. 混淆矩阵（Confusion Matrix）

二分类的四种结果如下：

| 真实值 \\ 预测值 | 预测正类 | 预测负类 |
|---|---:|---:|
| 真实正类 | TP（真正例） | FN（伪反例） |
| 真实负类 | FP（伪正例） | TN（真反例） |

- **TP（True Positive）**：真实为正，预测也为正。
- **FN（False Negative）**：真实为正，却预测为负；即漏检。
- **FP（False Positive）**：真实为负，却预测为正；即误报。
- **TN（True Negative）**：真实为负，预测也为负。

恒有：

$$TP + FN + FP + TN = \text{总样本数}$$

### 示例

共有 10 个样本：6 个恶性肿瘤（正类），4 个良性肿瘤（负类）。

| 模型 | TP | FN | FP | TN |
|---|---:|---:|---:|---:|
| A：识别出 3 个恶性、4 个良性 | 3 | 3 | 0 | 4 |
| B：识别出 6 个恶性、1 个良性 | 6 | 0 | 3 | 1 |

模型 A 更保守：误报少但漏掉了不少正类；模型 B 漏检少但误报更多。

## 5. Precision、Recall 与 F1-score

### 5.1 精确率（Precision）

在所有“预测为正”的样本中，真正为正的比例：

$$\operatorname{Precision} = \frac{TP}{TP+FP}$$

关注“报出来的正类有多少是真的”。误报（FP）成本高时更重要。

### 5.2 召回率（Recall / TPR / Sensitivity）

在所有真实正类中，被成功识别出的比例：

$$\operatorname{Recall} = \frac{TP}{TP+FN}$$

也叫查全率。漏检（FN）成本高时更重要，例如疾病筛查、欺诈识别、客户流失预警。

### 5.3 F1-score

F1 是 Precision 与 Recall 的调和平均数：

$$F_1 = \frac{2\times \operatorname{Precision}\times \operatorname{Recall}}
{\operatorname{Precision}+\operatorname{Recall}}$$

当希望同时兼顾精确率和召回率时使用。它不会因为其中一项极低而给出虚高的分数。

上述示例：

| 模型 | Precision | Recall | F1 |
|---|---:|---:|---:|
| A | $3/(3+0)=100\%$ | $3/(3+3)=50\%$ | $66.7\%$ |
| B | $6/(6+3)=66.7\%$ | $6/(6+0)=100\%$ | $80\%$ |

> 结论：没有脱离业务目标的“最好指标”。疾病初筛通常更看重 Recall；误报会带来高昂人工成本时则更看重 Precision。

## 6. ROC 曲线与 AUC

### 6.1 TPR 与 FPR

- 真正率（TPR）：即 Recall。

  $$TPR = \frac{TP}{TP+FN}$$

- 假正率（FPR）：在真实负类中，被误判为正类的比例。

  $$FPR = \frac{FP}{FP+TN}$$

### 6.2 ROC 曲线

ROC（Receiver Operating Characteristic）曲线以：

- 横轴：$FPR$；
- 纵轴：$TPR$；
- 每个点：一个分类阈值下的模型表现。

曲线越靠近左上角 $(0, 1)$，模型区分正负类的能力通常越强；对角虚线附近代表接近随机猜测。

常见特殊点：

| 点 | 含义 |
|---|---|
| $(0, 0)$ | 所有样本预测为负：没有误报，也没有识别出正类。 |
| $(1, 0)$ | 所有负类预测错，所有正类也预测错，属于最差表现。 |
| $(1, 1)$ | 所有样本预测为正：所有正类识别出，但所有负类都被误报。 |
| $(0, 1)$ | 完美分类器：正类全识别、负类无误报。 |

### 6.3 AUC 指标

AUC（Area Under the ROC Curve）是 ROC 曲线下的面积：

- AUC 越大，区分能力通常越好；
- AUC = 0.5：与随机猜测相当；
- AUC = 1：完美区分正负类；
- AUC < 0.5：排序方向可能反了（交换正负类或将分数取反后可改善）。

## 7. 快速复习

```text
特征 x
  ↓  线性加权：wᵀx + b
分数 z
  ↓  sigmoid
正类概率 p
  ↓  阈值 t
预测类别 0 / 1
  ↓  与真实标签对比
混淆矩阵 → Precision / Recall / F1 / ROC-AUC
```

1. 逻辑回归输出的是正类概率；阈值决定最终类别。
2. 交叉熵损失来自最大似然估计，训练目标是最小化负对数似然。
3. 混淆矩阵是多数分类指标的基础。
4. Precision 防误报，Recall 防漏报，F1 平衡两者。
5. ROC-AUC 衡量模型在不同阈值下的整体排序/区分能力。
