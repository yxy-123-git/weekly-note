# 损失函数

## 多分类任务交叉熵损失函数

在多分类任务通常使用softmax将logits转换为概率的形式，所以多分类的交叉熵损失也叫softmax损失，

L = −∑ᵢ yᵢ · log([S(f(x))]ᵢ)

其中：

1. y是样本x属于某一个类别的真实概率
2. f（x）是样本属于某一类别的预测分数
3. S是softmax激活函数，将属于某一类别的预测分数转换成概率
4. L用来衡量真实值y和预测值f(x)之间差异的损失结果

> 目的是最小化正确类别所对应的预测概率的对数的负值（损失值最小）

    y_pred=torch.tensor([[0.1,0.8,0.1],[0.7,0.2,0.1]],requirse_grad=true)

## 二分类任务损失函数

在处理二分类任务时，我们不在使用softmax激活函数，而是使用sigmoid激活函数，那损失函数也相应进行调整，使用二分类的交叉熵损失函数：

```math
L = -\left[ y \cdot \log(y') + (1-y) \cdot \log(1-y') \right]
```

其中：

1. y是样本x属于某一个类别的真实概率
2. y’是样本属于某一类别的预测概率
3. L用来衡量真实值y和预测值y'之间差异的损失结果

```
import torch
import torch.nn as nn

def dm02():
    y_true=torch.tensor([0,1,0],dtype=torch.float)
   
  
    y_pred=torch.tensor([0.6943,0.8458,0.1674],requirse_grad=true)
  
    criterion=nn.BCEloss()

    loss=criterion(y_pred,y_true)
    print(f'损失值{loss}')
if __name__=='__main__':
    dw02()
```

## 回归任务损失函数-MAE损失函数

> Mean absolute loss（MAE）也被称为L1 loss，是以绝对误差作为距离。损失函数公式：

```math
L = \frac{1}{n} \sum_{i=1}^{n} |f(x_i) - y_i|
```

其中：n为样本数量，y_i为第i个样本的真实值，f(x_i)为第i个样本的预测值

特点是：

1. 由于L1 loss具有稀疏性，为了惩罚较大的值，因此将其作为正则项添加到其他loss中作为约束。
2. L1 loss的最大问题是梯度在零点不平滑，导致会跳过极小值。

   ```
   import torch
   import torch.nn as nn

   def dm01():
       y_true=torch.tensor([2.0，2.0，2.0],dtype=torch.float)


       y_pred=torch.tensor([1.0，1.0，1.9],requirse_grad=true)

       criterion=nn.L1Loss()

       loss=criterion(y_pred,y_true)
       print(f'损失值{loss}')
   if __name__=='__main__':
       dw02()
   ```

## 回归任务损失函数-MSE损失函数

> Mean Squared Loss /Quadratic Loss (MSE loss)也被称为L2 loss，或者欧式距离，它以误差的平方和均值作为距离损失函数公式：

```math
L = \frac{1}{n} \sum_{i=1}^{n} (f(x_i) - y_i)^2
```

其中：n为样本数量，y_i为第i个样本的真实值，f(x_i)为第i个样本的预测值

特点是：

1. L2 loss也常常作为正则项
2. 当预测值与目标值相差很大时，梯度容易爆炸。

   ```
   import torch
   import torch.nn as nn

   def dm02():
       y_true=torch.tensor([2.0，2.0，2.0],dtype=torch.float)


       y_pred=torch.tensor([1.0，1.0，1.9],requirse_grad=true)

       criterion=nn.MSELoss()

       loss=criterion(y_pred,y_true)
       print(f'损失值{loss}')
   if __name__=='__main__':
       dw02()
   ```

## 回归任务损失函数-Smooth L1损失函数

```math
L(x) = \begin{cases} \frac{1}{2}x^2, & |x| \leq 1 \\ |x| - \frac{1}{2}, & |x| > 1 \end{cases}
```

其中：x=f（x）-y为真实值和预测值的差值

1. 在[-1,1]之间实际上就是L2损失，这样解决了L1的不光滑问题。
2. 在[-1,1]区间外，实际上就是L1损失，这样就解决了离群点梯度爆炸的问题。

   ```
   import torch
   import torch.nn as nn

   def dm03():
       y_true=torch.tensor([2.0，2.0，2.0],dtype=torch.float)


       y_pred=torch.tensor([1.0，1.0，1.9],requirse_grad=true)

       criterion=nn.SmoothL1Loss()

       loss=criterion(y_pred,y_true)
       print(f'损失值{loss}')
   if __name__=='__main__':
       dw03()
   ```

> MAE：平均绝对值误差  公式：误差绝对值之和/样本总数  类似于L1正则化，权重可以降维0，数据会变得稀疏  弊端：在0点不平滑，可能错过最小值
>
> MSE：均方误差  公式:误差平方之和/样本总数  弊端：如果差值过大，可能存在梯度爆炸的情况
>
> Smooth L1:就是基于MAE和MSE做的综合，在[-1，1]是L2（MSE），其他段是L1，这样解决了L1不平滑的问题，又解决了L2梯度爆炸问题
