# 批量归一化 Batch Normalization（BN）


## 核心思想

先对数据做标准化，再通过**缩放 + 平移**对数据重构。
标准化把数据拉到均值 0、方差 1；缩放平移是可学习变换，用来弥补标准化丢失的信息，让网络有能力恢复合适的数据分布。

公式：

\(f(x)=\gamma \cdot \frac{x - E(x)}{\sqrt{Var(x)+\epsilon}}+\beta\)- \(\gamma\)（也就是课件里的\(\lambda\)）：缩放系数，可学习参数
- \(\beta\)：平移偏置，可学习参数
- \(\epsilon\)：很小的常数（一般取 \(1e-5\)），防止分母为 0
- \(E(x)\)：一个批次内数据的均值
- \(Var(x)\)：一个批次内数据的方差

> 
> 大白话类比：
> 不加 BN：像乡村小道，车速很乱，1km/h ~130km/h 波动很大；
> 加上 BN：像高速公路，速度被约束在一个稳定区间，方便激活函数稳定工作。
> 典型例子：Sigmoid 激活函数只在 [-3,3] 区间效果好，标准化后数据分布更稳定，模型收敛更快。

## BN 的作用

1. **减少内部协方差偏移（Internal Covariate Shift）**
每一层的输入分布在训练时不断变化，BN 对每层输入标准化，稳定分布，让训练过程更平稳。
2. **加速训练**
深层网络不加 BN 时，前面层参数更新会持续改变后面层输入分布，学习很慢；BN 稳定输入分布，允许使用更大学习率，加快收敛。
3. **起到正则化效果**
每个批次的均值方差是基于当前批次采样计算的，批次带来的噪声相当于轻微扰动，降低模型对特定特征的依赖，减少对 Dropout 这类正则手段的依赖。
4. **提升泛化能力**
得益于上面的正则化效果，模型在测试集上通常能获得更好的效果。

> 
> 补充：BN 在计算机视觉领域使用非常广泛。

## BN 使用规范

1. **添加位置**
一般放在卷积层`Conv2d` / 全连接层`Linear`之后，激活函数之前。
顺序示例：`Conv2d → BN → ReLU``Linear → BN → ReLU`
2. **训练模式 `model.train()`**

- 计算当前这一个 batch 的均值\(\mu\)、方差\(\sigma^2\)
- 使用当前批次统计量对本批数据归一化、缩放平移
- 同步维护**全局均值、全局方差**的滑动平均值（给推理阶段用）

3. **推理模式 `model.eval()`**

- **不再使用当前 batch 的均值方差**
- 直接使用训练阶段保存好的全局滑动均值、全局滑动方差来做归一化
- 推理时\(\gamma\)和\(\beta\)直接使用训练完成后固定下来的参数

## 一句话总结

BN 用批次统计量把每层输入拉到稳定分布，再用可学习的 γ、β 还原表达能力，稳定训练、加速收敛、附带正则效果。
